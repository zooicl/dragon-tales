# SONO PLAY CLUB · 쏘냐 & 위냐

쏘냐·위냐와 함께 드래곤을 돌보고 다섯 가지 놀이, 네 곳의 탐험, 마을 꾸미기와 친구 교류를 즐기는 웹게임입니다.

플레이: https://zooicl.github.io/dragon-tales/

## 2.0 — 모든 콘텐츠 열림

레벨 잠금과 준비 중 카드를 제거했습니다. 화면에 있는 콘텐츠는 모두 시작하고 끝낼 수 있습니다.

| 영역 | 실제 플레이 기능 |
| --- | --- |
| 육성 | 알 5종, 이름, 돌보기 5종, Lv.1~30, 단계별 날개·왕관·수호자 외형 |
| 놀이 | 자유투, 15초 과일 놀이, 30초 하늘 날기, 3회 숨바꼭질, 5송이 마법 정원 |
| 탐험 | 숲 발자국, 동굴 수정 순서, 호수 별자리, 하늘 구름 길, 고유 별빛 조각 5개 |
| 마을 | 12×12 지도, 건물 6종, 구매·배치·이동·회수·저장·마지막 편집 되돌리기 |
| 생산 | 과일나무 5분마다 1개, 나무당 오프라인 최대 6개, 수확한 열매 보관 |
| 친구 | 소라·윈디·루미, 함께 놀기·무료 선물·마을 방문, 우정 Lv.1~5, 우정 추억 |
| 상점 | 별빛 공·꽃 리본·특별 간식 구매 및 실제 사용, 행복·친밀도·스타일 효과 |
| 도감 | 5종 모습을 자유롭게 선택, 꽃·별빛·무지개 스타일, 사건 당시 이름을 보존하는 추억 |
| 이야기 | 여섯 장면 전부 재감상, 별빛 나무 복원과 엔딩, 중복 없는 엔딩 보상 |
| 설정 | 이름, 모션 감소, 사용자 선택 효과음, JSON 백업·복원, 2단계 초기화 |

모든 종족은 처음부터 선택 가능하며, 도감에서 외형을 바꿀 때 기존 이름·성장·추억이 이어집니다. 별개의 다섯 저장 슬롯을 운영하는 구조는 아닙니다. 소리는 켠 뒤 상호작용에만 재생됩니다.

## 실행과 검증

Node.js 22 이상이 필요합니다.

```sh
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

`dist/` 정적 파일로 배포합니다. 의존성 버전은 `pnpm-lock.yaml`에 고정되어 있으며 GitHub Actions는 pnpm으로 설치한 뒤 검사와 빌드를 실행합니다.

## 저장 v2

IndexedDB `dragon-tales` → `saves` → `main-save`를 유지합니다. 기존 v1 데이터는 읽을 때 v2로 자동 변환하며 이름·종족·성장·코인·추억을 보존하고 새 필드를 기본값으로 보완합니다. 예전 JSON 백업도 가져올 수 있습니다. v2에는 친구, 건물, 아이템, 별빛 조각, 진화 스타일, 효과음 설정과 엔딩 상태가 포함됩니다.

검증되지 않은 백업은 적용하지 않습니다. 저장소 실패 시 원본을 자동 삭제하지 않고 현재 창에서 플레이를 이어가며 백업을 안내합니다. 기기·브라우저·주소가 달라지면 백업 파일로 옮겨 주세요.

탐험·미션·엔딩은 고유 키로 일회 보상을 지킵니다. 미니게임은 라운드당 한 번 지급합니다. 건물과 상품 구매는 잔액 검증 후 코인과 소유물을 함께 변경합니다. 마을 되돌리기는 다른 활동 이후 오래된 상태로 돌아가 데이터를 지우지 않도록 현재 상태를 확인합니다.

## GitHub Pages

`.github/workflows/deploy.yml`이 main 변경 시 타입 검사 → 테스트 → 빌드 → Pages 배포를 실행합니다. 저장소 Settings → Pages → Source는 GitHub Actions입니다. PR은 검증만 실행합니다.

## 구조

- `src/game.ts`: 공통 규칙, v1→v2 저장 변환, Zod 검증
- `src/expansion.ts`: 마을·거래·탐험·친구·엔딩의 순수 로직
- `src/Games.tsx`, `src/ExtraGames.tsx`: 다섯 미니게임과 숲
- `src/World.tsx`: 지도·퍼즐·마을·친구·상점·수집·엔딩
- `src/Dragon.tsx`, `src/ClubArt.tsx`: 드래곤과 쏘냐·위냐 SVG
- `src/club.css`, `src/expansion.css`: 아이폰·아이패드 반응형 인터페이스
- `src/sound.ts`: 외부 음원 없이 만드는 짧은 효과음

디자인 방향은 [DESIGN.md](DESIGN.md)에 정리했습니다. 팬 콘셉트 게임이며 개인정보 수집·결제·광고·랭킹은 없습니다. 실제 iOS 기기 검증과 브라우저 화면 크기 검증은 구분합니다.
